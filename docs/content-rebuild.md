# 活動・作品・実績ページの再構成

確認日：2026年11月1日（日本時間）。

## 基点と照合

ユーザー指定の[公開Notion「活動内容」](https://kumc-club.notion.site/330b66811ed780b3a6e7c7f326747bdf)と、その配下の主な活動6ページ・実績3ページを読み、Google DriveのKUMC資料と公開配布ページ・公式ブログで照合しました。Notionコネクタは対象を取得できなかったため、匿名で閲覧できる公開ページとブラウザ表示を使用しました。KUMC-Agentの接続ツールはこの環境にないため、Agentへの照会はしていません。

内部資料のURL・IDや原文はリポジトリ・配信物に入れず、以下には資料名と判断だけを記録します。

| 論点 | 確認資料 | 掲載判断 |
| --- | --- | --- |
| 活動頻度 | 「0-KUMC活動紹介（カラー）」（10月30日更新）、「KUMC 例会運営マニュアル」（9月25日更新） | 週1回を基本、試験期等は休会。曜日・時刻は固定しない |
| 実際の例会 | 「過去の例会の内容」（10月6日更新） | 5月9日のサバイバル、6月21日の建築伝言、7月11日のCreate、10月3日のゲーム等、実施内容がある記録を採用。8月9日の予定9種を全実施と書かない |

| 制作・会報誌 | 公開Notion、公式ブログ、「KUMC 同好会史」（9月30日更新）、「KUMC紹介資料」（8月27日更新） | 建築・ゲーム・KU匠を具体化。2026年NFの未開催企画や会報誌vol.3を完成実績にしない |

## 掲載先

- `/activities/`：Notionの6項目を軸に、実施したゲーム・頻度・制作方法・教育企画・技術活動を説明。
- `/works/`：配布中4作品の仕様、例会用ゲームのルール、会報誌。詳細ページには追加の実画像ギャラリー。
- `/achievements/`：2024〜2026年の7件と、エンドラRTA軍団との動画企画。日付・会場・担当を掲載。
- 公開画像の来歴は `docs/assets.md`。共通の白・青の配色、ヘッダー、書体を継承し、画像・キャプション・目次を追加。

固定文言の活動紹介と企画用ゲームは各一覧のAstroファイルで管理します。配布作品と開催実績は既存のMarkdownコレクションを継続し、`playMode`・`highlights`、`location`・`periodLabel`・`gallery`を追加しました。
