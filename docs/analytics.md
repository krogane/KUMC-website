# GA4・Search Console

GA4のアカウント・測定IDは未設定です。ローカル検証は通信を置き換えたテストであり、Googleで実受信した証拠ではありません。

## GA4の管理画面

1. KUMCが引き継げるGoogleアカウントでGA4プロパティを作成し、管理担当者を追加する。共有パスワードではなく各人の権限を管理する。
2. タイムゾーンを日本、WebストリームURLを `https://kumc-club.net` とする。測定IDをActions Variable `PUBLIC_GA_MEASUREMENT_ID` へ設定する。
3. **拡張計測を無効**にする。ページビューは実装が1回送信し、外部リンクも独自イベントだけにする。自動イベントとの重複を避ける。
4. Google Signals、広告連携、User-IDは有効にしない。データ保持でイベントデータの保持期間を **2か月**にする。
5. 説明欄・引き継ぎ資料に「拒否・ブロッカー等により全訪問者を網羅しない」「クリックは手続き完了数ではない」と記載する。

## 同意と送信内容

[Basic Consent Mode](https://developers.google.com/tag-platform/security/concepts/consent-mode)相当です。未同意・拒否時はgtag.jsもcookieless pingも読み込み／送信しません。本番設定・正規ホスト・有効な同意がすべて必要です。広告3項目は常時denied。選択の保存期間は180日で、保存不能・期限切れは未同意へ戻ります。別タブの撤回、ページ復帰、期限切れも監視します。

同意時は現在のページビューだけを1回送り、過去のクリックを後から送信しません。全クエリ・フラグメントを削除し、参照元はoriginまで。初期版ではUTMもすべて削除します。キャンペーン計測を追加する場合は値の許可リストを定め、任意入力を通さないでください。

| イベント | 意味 | 主なパラメータ |
| --- | --- | --- |
| `page_view` | 同意後のページ閲覧 | `page_location`, `page_referrer`, `page_title` |
| `join_click` | 入会方法・確認済み入会先・入会相談へのクリック | `placement`, `method` |
| `contact_click` | メール／Xで相談するリンクのクリック | `placement`, `method: email/x` |
| `work_download_click` | 外部の配布ページを開くクリック | `placement`, `work_id` |
| `social_click` | 公式アカウント・ブログ・配布元へのクリック | `placement`, `platform` |

許可される値は `public/scripts/privacy-core.js` で制限します。自由入力、メール、DM内容、任意URL全文は送りません。配布ページ遷移はワールドのダウンロード完了を意味しません。

撤回はフッターの「解析設定を変更」→「許可しない」。即座に送信停止フラグを設定し、現在のサイトが削除可能なGA Cookieを除去して再読み込みします。送信済みデータの消去は保証しません。X表示への同意とは独立です。

## 本番での確認

ブラウザのNetworkでログを保持し、サイトデータを消したテスト用ブラウザで次を確認します。ブロッカーの有無を記録してください。

1. 未選択・拒否・再読み込みでGoogleとXへの通信が0。
2. 許可後にgtag.jsが1回、現在の `page_view` が1回。GA4のリアルタイムで受信を確認する。
3. 入会・相談・作品配布・SNS各1クリックが意図したイベント1回として届く。値にクエリ・メール等が混入しない。
4. 設定変更から拒否し、Cookie削除・再読み込み後にタグがなく、その後送信されない。別タブでの撤回も確認する。
5. Xだけを表示してもGAへ送らない。GAを許可してもXはクリックするまで読み込まない。

DebugViewを使う場合は管理者のテスト端末だけでdebug_modeを一時有効にし、恒久設定としてコミットしないでください。CSPの拒否ログと実際の通信先を照合し、根拠なくワイルドカードを追加しません。

## Search Console

Search Consoleでドメインプロパティ `kumc-club.net` を追加し、提示されたTXTでDNS所有確認を行います。確認用値をこの資料へ書き写さず、DNS管理台帳で管理します。検証後 `https://kumc-club.net/sitemap.xml` を登録し、主要URLの検査で取得・canonical・noindexの状態を確認します。管理担当者を追加し、交代時に不要権限を削除します。現在は未登録です。検索順位やリッチリザルトの表示は保証しません。
